# Роли и зоны ответственности

Команда из 5 человек; совмещение ролей выбрано по рекомендациям из требований к проекту.

| Участник | Роль | Совмещение |
|----------|------|-----------|
| Ярослав | Data Engineer + Data Scientist / ML-инженер | 2 + 3 |
| Всеволод | MLOps/DevOps + Backend-разработчик | 4 + 5 |
| Андрей | Product Owner / Аналитик требований | 1 |
| Виталий | Frontend / Визуализатор | 6 |
| Роман | Тимлид / Scrum-мастер | 7 |

## Андрей — Product Owner / Аналитик требований
- Сбор и анализ требований, формулировка задач и критериев приёмки.
- Метрики успеха и пользовательские сценарии (см. [requirements.md](requirements.md)).
- Коммуникация с заказчиком, приоритизация backlog.
- Ведение RACI-матрицы.

## Ярослав — ML + Data Engineer
- Подбор модели Ollama и промптов (системный промпт сетевого инженера, формат tool-calling).
- Набор и разметка эталонных сценариев настройки (VLAN, port-security, trunk, ACL) для оценки качества.
- Валидация ответов модели, метрики (доля корректных команд, доля отклонённых небезопасных).
- Хранение датасета сценариев, воспроизводимость экспериментов (MLflow/DVC — по мере необходимости).

## Всеволод — DevOps + Backend
- API на FastAPI, интеграция с Ollama, коннекторы SSH/Telnet, цикл агента.
- Модуль безопасности команд и журнал аудита.
- Docker, docker-compose, CI/CD (GitHub Actions), логирование, мониторинг (Prometheus/Grafana).
- Автотесты backend.

## Виталий — Frontend / Визуализатор
- Интерфейс: дерево хостов, вкладки терминала (xterm.js), панель чата ассистента.
- Диалог подтверждения команд (diff «что будет выполнено»).
- Дашборды: статистика сессий, принятые/отклонённые команды.

## Роман — Тимлид / Scrum-мастер
- Планирование спринтов, ведение доски Jira/Trello, ретроспективы.
- Документация проекта, контроль сроков, ревью pull request'ов.
- Подготовка защиты проекта.

## RACI-матрица

R — исполнитель, A — ответственный, C — консультирует, I — информируется.

| Работа | Андрей | Ярослав | Всеволод | Виталий | Роман |
|--------|:-----:|:-------:|:--------:|:-------:|:-----:|
| Требования и сценарии | A/R | C | C | C | I |
| Архитектура | C | C | A/R | C | I |
| Backend API, коннекторы | I | C | A/R | C | I |
| Промпты и оценка модели | C | A/R | C | I | I |
| Безопасность команд | C | C | A/R | C | I |
| Frontend | C | I | C | A/R | I |
| Docker, CI/CD, мониторинг | I | I | A/R | C | C |
| Планирование и доска | C | I | I | I | A/R |
| Документация | C | C | C | C | A/R |
| Защита проекта | C | R | R | R | A/R |
